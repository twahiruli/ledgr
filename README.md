# Ledgr

AI-powered personal finance app built with Next.js 14, TypeScript, and Tailwind CSS.

## Features
- 📊 Dashboard with spending overview and budget tracking
- 🤖 AI transaction categorisation
- 💬 Natural language chat with your financial data
- 📈 Spending insights and month-over-month comparisons
- 🌙 Dark mode throughout

## Tech stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS

## Getting started
```bash
npm install
npm run dev
```
